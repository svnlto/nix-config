**Author**: James Stanier (Pragmatic Bookshelf) | ~385 pages | 18 chapters

A reference toolkit of the book's named frameworks. This file is a table of
contents — read the linked file for the level of detail the task needs.

## How to Use This Skill

- **Overview** — read [frameworks.md](frameworks.md) for the core frameworks
  and a topic → chapter index.
- **A topic** (`one-to-ones`, `hiring`, `delegation`) — find it in the chapter
  index below or in [frameworks.md](frameworks.md), then read that chapter.
- **A chapter** (`ch08`) — read that chapter file directly.
- **A decision** — [cheatsheet.md](cheatsheet.md) has When → Then → Why rules.

Apply the author's exact framework names; cite the chapter so the reader can go
deeper.
